Spike ordering rule: **no implementation phase begins while an assumption it depends on is unproven.** Gate column is normative — the listed phase's EXIT criteria include the spike's success (or its documented fallback). Time-box 1–3 days each; decision recorded in the owning ADR; code throwaway unless adopted.
